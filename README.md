# Temperature-Converter

## About

This repository contains a Temperature Converter web application developed using HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin through a simple and responsive user interface.

## Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Responsive and user-friendly interface
- Instant temperature conversion

- CSS3
- JavaScript
